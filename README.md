# Edyson Guevara — Portafolio Web

Portfolio profesional construido con React + Vite.

## Stack

- React 18 + Vite 5
- CSS puro con variables (sin frameworks externos)
- Google Fonts: Syne, DM Mono, DM Sans
- IntersectionObserver para animaciones en scroll

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy en Vercel

1. Sube el repositorio a GitHub.
2. En [vercel.com](https://vercel.com), importa el repositorio.
3. Vercel detecta Vite automáticamente — sin configuración extra.
4. Coloca tu foto en `public/edyson.jpg` antes de hacer push.

> Build command: `npm run build`  
> Output directory: `dist`
